AH LIGHTS — IPHONE INVENTORY APP (UPGRADED)

Features:
• Search by item code, item name, or category
• Category filters
• Quantity
• Retail price only
• Item detail screen
• Add Inventory directly from iPhone
• Edit and delete items added through the app
• Optional product photo for newly added items
• Bulk Inventory import using CSV or tab-separated rows
• Custom inventory is stored locally on the iPhone/browser using localStorage
• iPhone-style responsive interface
• Existing supplied inventory records preserved

BULK INVENTORY:
Open “Bulk Inventory” and paste rows in this format:
Code, Product Name, Category, Quantity, Retail Price

Example:
9087-8,CHANDLIER 9087-8,CHANDLIER,1,21000

For a future product-list picture, the picture can be converted into these rows and then imported in bulk.

IMPORTANT:
The current ZIP does not contain the AH Lights logo image. The header area is prepared, but the exact visiting-card logo should be added when the logo image is supplied again.

TO INSTALL AS AN IPHONE HOME-SCREEN APP:
1. Host this folder on any HTTPS web host.
2. Open the HTTPS address in Safari on iPhone.
3. Tap Share.
4. Tap Add to Home Screen.
5. Name it AH Lights and tap Add.
