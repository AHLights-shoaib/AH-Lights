AH LIGHTING — FINAL IPHONE INVENTORY APP

Open index.html to preview the app.

Features:
• Search by code or item name
• Category filters
• Quantity
• Retail price
• Sale price = Retail + Rs. 1,000
• Item detail screen
• iPhone-style responsive interface
• 177 visible item records from the supplied pages

TO INSTALL AS AN IPHONE HOME-SCREEN APP:
1. Host this folder on any HTTPS web host.
2. Open the HTTPS address in Safari on iPhone.
3. Tap Share.
4. Tap Add to Home Screen.
5. Name it AH Lighting and tap Add.

The app contains no product pictures, as requested for now.
